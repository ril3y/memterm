# memterm Remote for iPhone/iPad — v1 Implementation Plan (plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A universal iPhone/iPad app that pairs with a Mac running memterm and lets the person see any pane and type into it, over the existing blind relay, using the shared `MemtermRemoteKit`.

**Architecture:** The app's brain — the per-Mac session state machine, the models and the storage contracts — lives in a new Foundation-only SwiftPM target `MemtermRemoteApp` that builds for macOS and iOS, so it is unit-tested headlessly with `swift test` on the Mac. Only the SwiftUI screens, the Keychain/Secure Enclave implementations and the SwiftTerm view need an actual iOS app target. That app target's Xcode project is **generated by XcodeGen from a committed YAML spec**, never hand-edited, so a fresh checkout reproduces it and every change is a readable diff (founder decision 2026-10-01; Jev 1.0 on this, 0.8 on the logic-target split).

**Tech Stack:** Swift 5.10, SwiftPM, SwiftUI, UIKit (SwiftTerm's `TerminalView`), CryptoKit, Security (Secure Enclave + Keychain), VisionKit (`DataScannerViewController`), XcodeGen, Xcode 26.6, iOS 17 deployment target.

**Spec:** `docs/superpowers/specs/2026-09-28-ios-remote-app-design.md` (sections 2, 3.2, 3.3, 3.4, 3.6; section 3.5 links and 3.7 CI are plan 3).

## Global Constraints

- The app is **universal (iPhone + iPad)**, iOS 17 deployment target, bundle id `com.memterm.remote`, team `YJ6Y72HALX`.
- v1 is **view and type only**. The app never sends `newTab` or `unlock`, even though the host supports them.
- **Only the Fit button ever resizes the Mac's pane.** Rotation, split view, Slide Over and Stage Manager change only how much this viewer sees. A resize is visible to the person at the Mac and can disturb a running program there.
- `MemtermRemoteApp` imports **only Foundation** (plus `MemtermRemoteKit`). No SwiftUI, UIKit, Security or VisionKit — those live in the app target. This is what keeps it testable headlessly, and it is enforced by `scripts/check-extension-firewall.sh`.
- The phone's identity key is generated in the **Secure Enclave** and never leaves it; paired hosts are stored in the **Keychain**, device-only, no iCloud sync.
- The host's public key for the key schedule comes from **stored bytes**, never from a wire field.
- Foreground only: no background sessions, no push notifications.
- `.xcodeproj` is **generated and git-ignored**; `ios/project.yml` is the committed source of truth.
- Commit after every task with the session's attribution trailer.
- Run every command from the worktree root with literal paths; never `cd`, never variable-prefixed commands (a guard rejects both). Never bare `git stash`.

## Review Focus

Five conditions a person will meet that the spec implies but does not spell out; each has its test in the task that owns the code:

1. A pairing code that has expired, or whose `paired` reply names a different host than the QR did, must be refused with a readable reason and must leave no stored host — Task 2, `testExpiredCodeIsRefused` / `testMismatchedPairedReplyIsRefused`.
2. Two sessions must never run against one Mac at once: a second `start()` while a handshake is in flight supersedes the first rather than racing it, and the superseded one's reply is dropped — Task 1, `testSecondStartSupersedesTheHandshakeInFlight`.
3. A pane that disappears from the Mac while attached (closed there) must drop the viewer back to the tree with a readable reason, not leave a dead terminal — Task 1, `testAttachedPaneVanishingReturnsToTree`.
4. Backgrounding and returning must re-attach to the same pane when it still exists and fall back to the tree when it does not, without leaking the old session's keys — Task 1, `testForegroundReattachesWhenThePaneSurvives` / `testForegroundFallsBackToTreeWhenItDoesNot`.
5. A host that is offline, or revokes this device mid-session, must be shown as such rather than as a silent stall — Task 1, `testHostOfflineIsSurfaced` / `testRevokedMidSessionIsSurfaced`.

```swift
/// A Mac this device has been allowed into, as stored on the phone.
///
/// `publicKeySPKI` is the ONLY source of the host's identity for the key

    public var publicKeySPKI: Data

    public var name: String

        self.id = id; self.publicKeySPKI = publicKeySPKI
        self.relay = relay; self.name = name; self.pairedAt = pairedAt
    }
}
```

```swift
import Foundation
import MemtermRemoteKit

/// The flattened rows a viewer shows: one section per workspace, one row per
/// attachable pane. Built here rather than in the view so it is testable.
public struct ViewerRow: Equatable, Identifiable {
    public var id: String            // paneId
    public var workspaceName: String
    public var workspaceColor: String
    public var title: String         // tab title
    public var subtitle: String      // adapter · cwd
    public var attachable: Bool      // serial and locked panes are shown, disabled
}

public enum ViewerTree {
    /// Serial panes cannot be attached (their bytes do not pass the taps a
    /// viewer reads), and locked workspaces refuse; both are listed anyway so
    /// the person sees their whole Mac rather than a filtered half of it.
    public static func rows(from tree: RemoteTree) -> [ViewerRow] {
        tree.workspaces.flatMap { workspace in
            workspace.windows.flatMap { window in
                window.tabs.flatMap { tab in
                    tab.panes.map { pane in
                        ViewerRow(id: pane.id,
                                  workspaceName: workspace.name,
                                  workspaceColor: workspace.color,
                                  title: tab.title,
                                  subtitle: pane.cwd.map { "\(pane.adapter) · \($0)" } ?? pane.adapter,
                                  attachable: pane.adapter != "serial" && !workspace.locked)
                    }
                }
            }
        }
    }

    public static func contains(paneId: String, in tree: RemoteTree) -> Bool {
        rows(from: tree).contains { $0.id == paneId }
    }
}
```

`Tests/MemtermRemoteAppTests/HostSessionTests.swift`. These drive a REAL `RelayConnection` over a fake transport, so the wire path is exercised, not mocked:

```swift
import XCTest
import MemtermRemoteKit
import MemtermRemoteKitTesting
@testable import MemtermRemoteApp

@MainActor
final class HostSessionTests: XCTestCase {
    private var factory: FakeTransportFactory!
    private var scheduler: FakeScheduler!
    private var hostIdentity: RemoteIdentity!     // stands in for the Mac
    private var phoneIdentity: RemoteIdentity!
    private var paired: PairedHost!
    private var session: HostSession!
    private var output: [Data] = []

    override func setUp() async throws {
        try await super.setUp()
        factory = FakeTransportFactory(); scheduler = FakeScheduler()
        hostIdentity = RemoteIdentity.generate(); phoneIdentity = RemoteIdentity.generate()
        output = []
        paired = PairedHost(id: hostIdentity.id, publicKeySPKI: hostIdentity.publicKeySPKI,
                            relay: URL(string: "wss://relay.example.test")!,
                            name: "Mac mini", pairedAt: Date())
        session = HostSession(host: paired, signer: phoneIdentity) { [self] url, events in
            RelayConnection(base: url, role: .client, signer: phoneIdentity, events: events,
                            transports: factory, schedule: { [self] d, b in scheduler.schedule(d, b) })
        }
        session.onOutput = { [self] in output.append($0) }
    }

    // -- helpers: drive the relay and the Mac by hand ----------------------

    private func authenticate() {
        factory.current.push(["type": "challenge",
                              "nonce": Data(repeating: 3, count: 32).base64EncodedString()])
        factory.current.push(["type": "authed", "id": phoneIdentity.id])
    }

    /// The Mac's side of the handshake: read the phone's Hello off the wire,
    /// answer with ours, and return the session keys the Mac would hold.
    private func completeHandshake() throws -> RemoteSessionKeys {
        let sent = factory.current.sentEnvelopes.last!
        let theirHello = try XCTUnwrap(HelloWire.decode(sent.payload))
        let (mine, ephemeral) = RemoteHandshake.makeHello(identity: hostIdentity)
        let keys = try RemoteHandshake.deriveKeys(ephemeralPrivate: ephemeral,
                                                  peerEphemeralRaw: theirHello.ephemeralRaw,
                                                  hostId: hostIdentity.id,
                                                  deviceId: phoneIdentity.id,
                                                  iAmHost: true)
        factory.current.push(["type": "env", "to": phoneIdentity.id, "from": hostIdentity.id,
                              "payload": HelloWire.encode(mine).base64EncodedString()])
        return keys
    }

    private func send(_ message: RemoteMessage, with keys: RemoteSessionKeys) throws {
        let sealed = try keys.seal(message.encode())
        factory.current.push(["type": "env", "to": phoneIdentity.id, "from": hostIdentity.id,
                              "payload": sealed.base64EncodedString()])
    }

    private func tree(panes: [String]) -> RemoteTree {
        RemoteTree(workspaces: [
            RemoteWorkspace(id: "w1", name: "Default", color: "#888888", locked: false, parked: false,
                            windows: [RemoteWindow(id: "win1", tabs: [
                                RemoteTab(id: "t1", title: "zsh",
                                          panes: panes.map { RemotePane(id: $0, adapter: "shell", cwd: "/tmp") })
                            ])])
        ])
    }

    // -- the tests ---------------------------------------------------------

    func testStartHandshakesListsAndBecomesReady() throws {
        session.start()
        XCTAssertEqual(session.phase, .connecting)
        authenticate()
        XCTAssertEqual(session.phase, .handshaking)
        let keys = try completeHandshake()
        // The phone asks for the tree as soon as it has keys.
        XCTAssertEqual(try keys.open(factory.current.sentEnvelopes.last!.payload),
                       RemoteMessage.list.encode())
        try send(.tree(tree(panes: ["p1"])), with: keys)
        XCTAssertEqual(session.phase, .ready)
        XCTAssertEqual(ViewerTree.rows(from: try XCTUnwrap(session.tree)).map(\.id), ["p1"])
    }

    func testAttachDeliversScreenThenOutput() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        try send(.screen(cols: 80, rows: 24, bytes: Data("hello".utf8)), with: keys)
        XCTAssertEqual(session.phase, .attached(paneId: "p1"))
        XCTAssertEqual(output, [Data("hello".utf8)])
        try send(.output(Data(" world".utf8)), with: keys)
        XCTAssertEqual(output.map { String(decoding: $0, as: UTF8.self) }, ["hello", " world"])
    }

    func testTypingSealsInputInOrder() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        let before = factory.current.sentEnvelopes.count
        session.input(Data("a".utf8)); session.input(Data("b".utf8))
        let sent = factory.current.sentEnvelopes.suffix(from: before)
        XCTAssertEqual(try sent.map { try keys.open($0.payload) },
                       [RemoteMessage.input(Data("a".utf8)).encode(),
                        RemoteMessage.input(Data("b".utf8)).encode()],
                       "records must arrive in the order they were sealed")
    }

    func testAttachedPaneVanishingReturnsToTree() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        try send(.screen(cols: 80, rows: 24, bytes: Data()), with: keys)
        // The Mac closed the pane: tree-changed, then a tree without it.
        try send(.treeChanged, with: keys)
        try send(.tree(tree(panes: ["p2"])), with: keys)
        XCTAssertEqual(session.phase, .ready, "a vanished pane drops the viewer back to the tree")
    }

    func testSecondStartSupersedesTheHandshakeInFlight() throws {
        session.start(); authenticate()
        let stale = factory.current.sentEnvelopes.last!     // the first Hello
        session.start()                                      // supersede it
        authenticate()
        let keys = try completeHandshake()
        // The Mac's reply to the SUPERSEDED Hello must not produce a session.
        let (otherHello, _) = RemoteHandshake.makeHello(identity: hostIdentity)
        factory.current.push(["type": "env", "to": phoneIdentity.id, "from": hostIdentity.id,
                              "payload": HelloWire.encode(otherHello).base64EncodedString()])
        try send(.tree(tree(panes: ["p1"])), with: keys)
        XCTAssertEqual(session.phase, .ready, "the live handshake's keys are the ones in force")
        XCTAssertNotEqual(stale.payload, factory.current.sentEnvelopes.last!.payload)
    }

    func testForegroundReattachesWhenThePaneSurvives() throws {
        session.start(); authenticate()
        var keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        try send(.screen(cols: 80, rows: 24, bytes: Data()), with: keys)
        session.sceneWentToBackground()
        XCTAssertEqual(session.phase, .idle)
        session.sceneBecameActive()
        authenticate()
        keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        XCTAssertEqual(session.phase, .attached(paneId: "p1"), "re-attaches to the same pane")
    }

    func testForegroundFallsBackToTreeWhenItDoesNot() throws {
        session.start(); authenticate()
        var keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        try send(.screen(cols: 80, rows: 24, bytes: Data()), with: keys)
        session.sceneWentToBackground()
        session.sceneBecameActive()
        authenticate()
        keys = try completeHandshake()
        try send(.tree(tree(panes: ["p2"])), with: keys)
        XCTAssertEqual(session.phase, .ready)
    }

    func testHostOfflineIsSurfaced() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        factory.current.push(["type": "offline", "hostId": hostIdentity.id,
                              "lastSeen": Date().timeIntervalSince1970 * 1000])
        guard case .offline = session.phase else {
            return XCTFail("expected .offline, got \(session.phase)")
        }
    }

    func testRevokedMidSessionIsSurfaced() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        session.attach(paneId: "p1")
        factory.current.push(["type": "refused", "reason": "not-allowed"])
        guard case .failed(let message) = session.phase else {
            return XCTFail("expected .failed, got \(session.phase)")
        }
        XCTAssertTrue(message.lowercased().contains("no longer"), "says the Mac revoked us: \(message)")
    }

    func testUnreadableRecordDropsTheSessionRatherThanStalling() throws {
        session.start(); authenticate()
        let keys = try completeHandshake()
        try send(.tree(tree(panes: ["p1"])), with: keys)
        // A record sealed under the wrong keys: the counter check fails.
        let wrong = try RemoteSessionKeys(sendKey: Data(repeating: 9, count: 32),
                                          recvKey: Data(repeating: 8, count: 32))
        factory.current.push(["type": "env", "to": phoneIdentity.id, "from": hostIdentity.id,
                              "payload": try wrong.seal(RemoteMessage.treeChanged.encode()).base64EncodedString()])
        guard case .failed = session.phase else {
            return XCTFail("expected .failed, got \(session.phase)")
        }
    }
}
```

`Sources/MemtermRemoteApp/Session/HostSession.swift`. The shape, with the reasoning that matters:

```swift
import Foundation
import MemtermRemoteKit

/// One paired Mac, while the app is in the foreground and that Mac is on
/// screen. Owns the relay connection, the handshake, the session keys and
/// the attached pane.
///
/// Main-actor throughout: `RelayConnection` requires main-queue calls, and
/// `RemoteSessionKeys`' counters must be consumed in order — doing both on
/// one actor is what makes "records go out in the order they were sealed"
/// true by construction rather than by care.
@MainActor
public final class HostSession: ObservableObject {
    public enum Phase: Equatable {
        case idle, connecting, handshaking, ready
        case attached(paneId: String)
        case offline(since: Date?)
        case failed(String)
    }

    @Published public private(set) var phase: Phase = .idle
    @Published public private(set) var tree: RemoteTree?
    public var onOutput: ((Data) -> Void)?

    private let host: PairedHost
    private let signer: RemoteSigner
    private let makeConnection: (URL, RelayConnection.Events) -> RelayConnection
    private var connection: RelayConnection?
    private var keys: RemoteSessionKeys?
    /// The handshake in flight, and the generation that identifies it. A
    /// second `start()` bumps the generation, so the Mac's reply to a
    /// superseded Hello is dropped rather than racing the live one.
    private var pendingEphemeral: RemoteHandshake.Ephemeral?
    private var handshakeGeneration = 0
    private var attachedPaneId: String?
    /// Survives a background/foreground cycle so the viewer comes back to
    /// the pane it was on, when that pane still exists.
    private var lastAttachedPaneId: String?

    public init(host: PairedHost, signer: RemoteSigner,
                makeConnection: @escaping (URL, RelayConnection.Events) -> RelayConnection) {
        self.host = host; self.signer = signer; self.makeConnection = makeConnection
    }

    // start() builds the connection with Events wired to the three handlers
    // below and calls connection.start(); phase = .connecting.
    //
    // onControl: "authed" -> begin the handshake (phase .handshaking, bump
    //   the generation, make a Hello, send it as a CLEAR envelope);
    //   "offline" -> phase .offline(since:); "online" -> start() again;
    //   "refused" with reason "not-allowed" -> phase .failed("This Mac no
    //   longer allows this device."); any other "refused" -> .failed(reason).
    //
    // onEnvelope: with no keys yet, treat the payload as the Mac's Hello:
```
